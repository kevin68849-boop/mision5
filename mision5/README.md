# Citadel — Misión 5

Landing page de una plataforma ficticia de hosting de videojuegos.

## Instalación

Sobre un proyecto Vite con React, instalar `tailwindcss@4` y `@tailwindcss/vite@4` y copiar estos archivos.

Ejecutar `npm run dev`.
